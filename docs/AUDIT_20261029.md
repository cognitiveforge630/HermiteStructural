## What the extra density point actually shows

Both cases use the same Redwood basis, end force, gravity and Hermite fixed-spin
boundary conditions; their mesh density differs in two dimensions. The source
values below are computed by `tools.section_refinement.read_case` from the
matching `samples/*.json` and `*_source_sections.json` files (midpoint sections,
source Gauss cross-section integration):

| Mesh | Tip discrepancy vs beam (%) | Max middle-half midpoint shear-resultant discrepancy (%) | Max middle-half midpoint moment discrepancy (%) |
|:---|---:|---:|---:|
| 5×5×129 | 1.773562 | 0.002908 | 0.366085 |
| 7×7×17 | 1.062607 | 2.079855 | 0.994642 |

Relative to 5×5×129, the independently solved 7×7×17 tip is closer to the
one-dimensional beam reference, **but both integrated section-resultant
comparisons are further away**. This does **not** state that the actual maximum
shear stress or principal stress increases with refinement. The x-axis is
categorical, and the 7×7×17 value shares nz=17 only as a comparison marker.

## Reproduction: verified plotting and small-run workflow

Run from the repository root in PowerShell; no virtual environment is needed.

```powershell
python -m pip install -r requirements.txt
python -m tools.audit_documentation
python -m tools.plot_cubic_densification
python -m tools.plot_p_order_comparison
python -m unittest discover -s tests -v

# Tiny nodal Hex64 integrated mesh → solve → report → fields workflow:
python -m tools.convergence_study --stage all --order 3 --levels "2,2,4" --out outputs/hex64_smoke
# Inspect the generated report and FE/reference stress maps:
Get-Content outputs/hex64_smoke/report.md
# For interactive 3D views AFTER installing PyVista:
python -m tools.nodal_field_viewer outputs/hex64_smoke/hex64_2x2x4.npz --field "Tau yz (psi)"
```

To regenerate the published source figure, `tools.plot_cubic_densification`
loads **existing** solved JSON, and does not launch a new FEM solve. The other
chart comes from the included **recorded summary**. To produce fresh Hex27 or
Hex64 raw results, follow the solve commands in
[the complete visual workflow](HEX27_HEX64_VISUAL_WORKFLOW.md) and
[higher-order study](HIGHER_NODE_HEX27_HEX64_STUDY_20261027.md).

## Validation gates

- On the final revised archive, **104 tests ran; 2 skipped**, all remaining tests passed. Both `--stage all` Hex64 and a saved small Hex27 and Hex64 16-cell solver run completed successfully.

- All tests are exercised by `python -m unittest discover -s tests -v`;
  two PyVista/VTK tests may be skipped if VTK is unavailable.
- Static documentation check: all 85+ local Markdown links and 230+ concrete
  documented Python commands across the Markdown set point to existing files
  or package modules. This is an *entrypoint existence* check, not execution of
  every computationally expensive example.
- Regeneration functions are tested against preserved source-section results,
  including the explicit `7×7×17` separation and plot export. Exact measured
  source values are asserted to prevent hand-entered/invented plot values.
- Shipped 3×3×5 Hex27 and Hex64 solved field archives are checked for consistent finite data, 16 source cells, and low free-DOF residuals.
- A complete small-mesh `--stage all` Hex64 solve checks the generated report,
  field archive and FE/reference heatmap. Original Hermite and nodal unit tests
  cover polynomial modes, element traction and small mechanics/equilibrium.
- **Not validated here:** Windows 11 PyVista GUI controls and graphics driver,
  manual field views, dense 192-cell Hex64 factorization or RAM usage,
  high-resolution 5×5×257 solves (none recorded), complete 3D stress-error
  convergence and certified a posteriori estimation.

**Scientific caution:** The near-zero shear-discrepancy 5×5×129 number is a
sampled *integrated section force* relative to a classical beam reference.
It is not a guaranteed estimate of local tensile, compressive, shear or von
Mises stress errors. Differences in section positions, transverse resolution
and essential boundary constraints may all affect comparisons.

## Correction issued after the original 29 October archive audit

**The original audit's description of source-center Hex27/Hex64 stress is
superseded.** The numerical stress-export method was corrected to direct
95%-inset visualization-subcell corner stress sampling. The included 16-element
Hex27 and Hex64 NPZ archives, source JSON and heatmap are regenerated. Old
centroid-only field archives are rejected by current viewers. The older
release's ~52.6 psi maximum from the Hex64 smoke screenshot is not valid as a
maximum-stress comparison. The fresh inset-corner smoke **sampled** peak is
~129.69 psi von Mises, not a certified or converged physical maximum.
See [the mandatory no-centroid policy](NO_CENTROID_STRESS_POLICY.md).
